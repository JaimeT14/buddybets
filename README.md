# BuddyBets

A single-page betting app that uses play money, built for a friend group to
make friendly wagers without real currency.

## Features
- Add and manage players, each with a coin balance
- Create custom wagers and settle them when the outcome is known
- Running ledger of every bet and payout
- Data saved in the browser with localStorage, so it persists between visits
- Dark theme

## Built with
HTML, CSS, JavaScript

## How to use
Open the live site, or download the repository and open `index.html` in a browser.

## What I learned
Managing application state in the browser, and tracking down a coin
calculation bug by tracing balances through each step of a settlement.
